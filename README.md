# Loom

Loom 是一个本地优先的个人桌面工作台，面向 Windows 和 macOS，将任务安排、信息记录、资料整理、邮件和音乐集中到一个应用中。打开工作台，可以查看今天需要处理的事项，记录临时想法，整理资料，或在周回顾中安排下一周。

Agent 是工作台各模块的统一对话入口，集成待办与日历查询、笔记和资料读取、邮件查询与发送、音乐搜索与播放等功能。用户可以用自然语言表达需求，由 Agent 调用对应模块获取信息、生成操作提案，并在确认后将结果写回业务模块。它还结合持续目标与已审核的长期记忆生成每日简报、跟进数据变化，并在用户开启邮件监测后分析新邮件，让信息查询、事项安排与后续跟进衔接起来。

工作台业务数据默认保存在本机；Agent、邮箱、音乐及手机推送在使用时需要连接对应服务。模型服务由用户配置，API 密钥和邮箱授权码通过系统安全存储加密保护。

## 功能模块

### 今日

“今日”是工作台的日常入口，汇总当前待办、近期日程、Agent 提醒和最近收集的内容。用户可以先查看需要处理的事项，再进入对应模块继续操作，无需逐个打开清单查找。

- 基于已有本地记录汇总事项，展示任务时间和相关提醒。
- 从 Agent 建议进入对话，或继续处理待安排的行动。
- 查看最近记录的笔记与资料，回到对应内容。

### 待办

待办模块管理任务的开始时间、截止时间、重复规则与完成状态。任务可以关联 Agent 持续目标，完成或移除任务时同步对应行动状态。

- 新建、编辑、完成和删除任务，查看临近截止或已逾期事项。
- 设置重复任务及循环结束日期，管理需要持续处理的事情。
- 将任务安排与日历联动，在时间视图中查看已有事项。
- 将生日等重要日期与对应待办关联，生成后续安排。

### 日历

日历按日期展示任务与安排，方便从时间维度查看工作量。选择某一天后，可以查看当天事项，并直接新建或调整任务的日期、时间和重复规则。

日历与待办共用任务数据，修改后的安排会反映在对应清单中，减少重复维护同一事项。

### 备忘录

备忘录用于记录临时想法、工作笔记和待整理的信息，支持标题与正文编辑、搜索以及基础 Markdown 展示，包括标题、列表和勾选项。

笔记可作为 Agent 查询和分析的上下文，也会出现在近期收集与周回顾中，方便把记录重新带回当前工作。

### 资料

资料模块集中管理导入文件与应用内创建的文档，支持分类、搜索、排序、重命名和内容编辑。未分类资料可以先收集，再逐步整理。

- 导入本地文件，或在工作台中创建文档。
- 按分类组织资料，处理重名文件，保留文件与资料记录的关联。
- 对支持的 PDF、图片等格式提供预览；不支持的格式不会强行内嵌展示。
- 将资料记录纳入工作台上下文，供 Agent 查询与分析。

### 邮箱

邮箱支持通用 IMAP 收信与 SMTP 发信，用户配置服务器信息和授权码后，可以在工作台中查看邮件文件夹、列表与正文，标记已读，并撰写和发送邮件。

- 连接前验证邮箱配置，解析邮件正文和附件信息。
- 清理邮件 HTML，并在受限环境中展示富文本正文。
- 用户明确要求时，Agent 可查询邮件列表或读取指定邮件；读取正文会标记该邮件为已读。
- 开启新邮件监测后，按增量记录分析新邮件，结合推广邮件过滤生成优先级建议，必要时提供待办提案供用户确认。

### Agent

Agent 将工作台中分散的功能集中到一个对话入口。用户用自然语言说明需求，Agent 根据需要调用待办、日历、备忘录、资料、邮箱和音乐模块，结合获取的信息给出答复或生成可执行的提案。对话中的操作与对应业务模块共用数据，确认创建的任务会出现在待办和相关日历视图中，确认保存的笔记会进入备忘录，音乐搜索与播放也会同步到音乐界面。

**集成各模块功能**

- **待办与日历：**读取任务和指定日期范围内的安排，结合当前时间梳理事项，生成新待办提案；支持保存重要日期，并将行动关联到持续目标。
- **备忘录与资料：**读取笔记摘要、资料名称、分类及工作台文档摘要，将记录作为当前问题的背景；可以生成笔记保存提案，将需要保留的信息写入备忘录。
- **邮箱：**按用户要求查询收件箱、读取指定邮件，结合邮件内容整理信息或生成待办提案；邮件发送先展示收件人、主题和正文供用户确认。
- **音乐：**查询已同步歌单与曲目，搜索并播放歌曲，根据实际歌单分析音乐偏好；收藏或移除歌单曲目时先生成确认提案。

这些模块可以在同一会话中协同使用，让邮件中的事项进入待办、让对话中的信息保存为笔记，也让已有任务和资料成为后续建议的依据。各模块页面负责查看和编辑具体内容，Agent 负责理解需求、选择工具并衔接操作。

Agent 支持流式回复，用户可配置多组 OpenAI 兼容模型服务，并按需要切换。

**工具调用与操作确认**

Agent 将工具查询结果或错误反馈给模型，继续分析下一步，单次请求最多进行 8 轮工具调用。创建待办、保存笔记、发送邮件、修改歌单等操作先生成确认卡片，用户确认后由主进程重新校验并执行。操作记录保存执行状态和结果；重复提交复用成功结果，外部操作结果不明确时停止自动重试。

**长期记忆与 Skill**

需要长期保留的信息或可复用流程先生成候选记忆、候选 Skill，用户审核后才会启用。Agent 按当前问题的相关性选取最多 6 条记忆和 3 项 Skill 加入上下文，支持归档、替换与恢复，并记录 Skill 的使用情况。

**持续目标**

用户可以创建持续目标，将待办和主动建议关联到目标。行动状态随处理结果更新，目标保留进度与历史记录，支持暂停、完成、重新跟踪和归档恢复。

**主动建议与后续跟进**

应用运行期间，Agent 可生成每日简报，并在工作台数据变化后执行只读分析。连续变更通过 15 秒窗口合并，事件跟进每天最多运行 3 次；提醒结合免打扰时段与每日通知上限送达。用户可以将建议确认安排为待办、延后查看，或围绕建议继续同一会话。主动检查不会在后台直接执行数据写入提案。

### 音乐

音乐模块接入网易云音乐，支持扫码登录、歌单同步、歌曲搜索和播放，提供播放队列、歌词及正在播放页面。

Agent 可以读取已同步歌单、查询曲目、搜索并播放歌曲，也可以基于实际歌单数据分析音乐偏好。收藏到歌单等修改操作会先检查歌单归属，再由用户确认。歌曲能否完整播放取决于账号权限与服务提供的音源，试听内容会显示对应提示。

### 周回顾

周回顾汇总本周事项、逾期任务、下周安排与近期笔记，帮助用户检查未完成的事情并整理后续计划。统计依据已有记录生成，不根据缺失的完成时间推算历史完成数量。

用户可以从符合条件的未安排待办中生成下周计划草稿，调整日期和时间后一次确认写入 1～3 项安排。写入前统一校验任务状态、重复标识和时间范围，再一次性更新任务的开始时间，保留原有截止时间。

### 快捷录入

通过侧边栏入口或 `⌘K` / `Ctrl+K` 唤起快捷录入，使用 `/todo`、`/event`、`/note` 指定事项类型。输入先解析为预览草稿，确认保存后再写入对应模块，方便快速记录任务、日程和笔记。

### 设置、通知与数据恢复

设置集中管理个人背景、长期规则、Agent 沟通方式、模型服务、通知和音乐服务连接。

- 配置多组模型服务，已保存的密钥不在页面中回显。
- 设置提醒提前量、免打扰时段及每日上限，按需配置 ntfy 或 Bark 手机推送。
- 手动备份、导出数据，并从已有恢复点恢复；备份与导出不包含密钥，恢复前会保存当前版本。
- Windows 提供应用内更新检查、下载和用户确认后的重启安装；macOS 通过下载新版安装包手动更新。

## 架构与数据

技术栈为 Electron、React、TypeScript、Node.js 和 Vite。React 页面通过预加载桥调用受控 IPC 接口，由主进程中的业务服务校验参数、访问外部服务并读写本地数据。渲染进程启用上下文隔离与沙箱，不直接访问 Node.js。

业务数据默认保存在系统用户数据目录中的 `workbench-data.json`，写入采用临时文件原子替换。API 密钥与邮箱授权码使用 Electron `safeStorage` 加密，备份和导出会移除敏感凭据。

项目包含 Agent、数据存储、操作状态、邮箱、安全及更新等模块自测，以及使用独立临时数据目录的 Electron 运行时冒烟测试。GitHub Actions 在 Windows 与 macOS 构建环境运行测试、生成安装包和校验文件，并创建 Release 草稿。跨平台实机验证范围以对应版本说明为准。

详细设计见 [架构说明](docs/ARCHITECTURE.md)，安装包交付步骤见 [发布说明](docs/RELEASING.md)。

## 快速开始

开发环境使用 Node.js 22.12 或更新版本（建议 Node.js 24）。当前 Electron 44 运行时要求 macOS 13 或更新版本；Windows 面向 64 位系统，安装包仍需完成独立构建与实机验证。

首次安装依赖（Electron 体积较大，可能需要一两分钟）：

```bash
cd desktop
npm install
cd ..
```

如果 `npm install` 长时间卡住，通常是系统代理挡了 Electron 下载；可以取消代理后重试，或先设置 `ELECTRON_MIRROR=https://npmmirror.com/mirrors/electron/` 再安装。

启动开发模式：

```bash
npm run dev
```

常用命令：

```bash
npm run typecheck
npm run build
npm run start
npm --prefix desktop run pack:mac
npm --prefix desktop run dist:mac:unsigned
```

依赖安全回归包含在 `npm --prefix desktop test` 中。验证真实 Electron 前端、IPC、主进程和内置服务可运行 `npm --prefix desktop run runtime-smoke-test`；它使用独立的临时数据目录，不读取个人账号或数据，运行前需关闭占用 3000 端口的 Loom 实例。

macOS 使用 `npm --prefix desktop run release:mac` 生成未签名 DMG，供用户下载并手动安装或覆盖更新；不需要 Apple Developer 账号，暂不提供应用内更新。首次打开可能出现系统安全提示。Windows 在 Windows 构建机上设置固定 HTTPS 地址 `LOOM_UPDATE_URL` 后运行 `npm --prefix desktop run release:win`，生成 x64 NSIS 安装包及更新元数据，支持用户确认下载和重启更新。Windows 实机安装与跨版本更新仍需验收。完整步骤见 [docs/RELEASING.md](docs/RELEASING.md)。

安装包见 [GitHub Releases](https://github.com/sleep-zzz520/Loom/releases/latest)：Windows 下载 x64 `.exe`，Apple Silicon Mac 下载 arm64 `.dmg`。Windows 保留应用内更新；macOS 下载新版安装包手动更新。系统要求和验证范围见对应版本说明。
