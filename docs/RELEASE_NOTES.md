Loom 0.2.0 将设置改为独立页面。打开设置后，可从左侧分类切换个人资料、通知、Agent、模型服务、GitHub、音乐服务、数据恢复和应用更新；左上角的返回按钮会回到进入设置前的页面。

Agent 新增 GitHub 连接。配置访问令牌后，可以查询仓库、文件、Issue 和 Pull Request。创建 Issue 时，Agent 会先展示仓库、标题和正文，等待确认后再提交。令牌保存在本机系统安全存储中，备份和导出不包含令牌。当前不支持通过 Agent 合并 Pull Request 或推送代码。

本周回顾把需要收尾的事项、本周安排、本周收集和下周安排放在固定位置；没有记录时仍显示对应区域。音乐发现页的“换个心情”改用四张方形封面，标题和预览歌曲紧跟封面，两个歌单区域的标题间距也已协调。

## 下载与安装

- Windows x64：下载 `Loom-Setup-0.2.0-x64.exe` 并按安装向导操作。支持应用内检查更新、下载、取消下载与重启安装。
- macOS Apple Silicon：下载 `Loom-0.2.0-arm64.dmg`，将 Loom 拖入“应用程序”。要求 macOS 13 或更新版本；Intel Mac 暂无对应安装包。
- macOS 暂不提供应用内更新。退出 Loom 后，用新版应用替换旧应用即可。

安装包未使用付费开发者证书签名，macOS 未公证。系统可能显示身份不明的开发者或 SmartScreen 提示。

## 验证范围

发布流水线在 Windows 和 macOS 上运行构建与项目自动测试，并分别生成安装包。本机 Electron 运行检查覆盖页面渲染、IPC、数据持久化、系统凭据加密及内置音乐服务启动。GitHub MCP 的工具调用与确认流程由模拟服务测试；真实账号连接仍需另行验收。

真实账号下的 Agent 播放、歌单封面加载，以及 Windows 全新安装和跨版本更新仍待实机验收。

`latest.yml` 和 `.exe.blockmap` 供 Windows 更新程序使用，用户无需手动打开。`SHA256SUMS.txt` 提供下载文件的 SHA-256 校验值。
