Loom 0.1.5 新增多模型服务配置，可以保存多套服务地址、模型和密钥，并选择默认模型。旧版单模型配置会自动迁移；密钥继续通过系统安全存储加密，导出和备份不携带密钥。

本次修复了聊天 Agent 与音乐页面使用不同服务地址的问题。使用内置音乐服务时，Agent 搜索和播放歌曲现在会读取服务的实际端口。我的歌单列表会将 HTTP 封面地址转为 HTTPS，图片加载失败时显示默认歌单图标。

“系统与 Agent”设置按功能分区，模型列表与编辑区分别滚动。音乐发现页调整了布局，避免内容被底部播放器遮挡。

## 下载与安装

- Windows x64：下载 `Loom-Setup-0.1.5-x64.exe` 并按安装向导操作。支持应用内检查更新、下载、取消下载与重启安装。
- macOS Apple Silicon：下载 `Loom-0.1.5-arm64.dmg`，将 Loom 拖入“应用程序”。要求 macOS 13 或更新版本；Intel Mac 暂无对应安装包。
- macOS 暂不提供应用内更新。退出 Loom 后，用新版应用替换旧应用即可。

安装包未使用付费开发者证书签名，macOS 未公证。系统可能显示身份不明的开发者或 SmartScreen 提示。

## 验证范围

发布流水线在 Windows 和 macOS 上运行构建与项目自动测试，并分别生成安装包。本机 Electron 运行检查已覆盖页面渲染、IPC、数据持久化、系统凭据加密及内置音乐服务启动。

真实账号下的 Agent 播放、歌单封面加载，以及 Windows 全新安装和跨版本更新仍待实机验收。

`latest.yml` 和 `.exe.blockmap` 供 Windows 更新程序使用，用户无需手动打开。`SHA256SUMS.txt` 提供下载文件的 SHA-256 校验值。
